# Apchi

Apchi — веб-мессенджер с фокусом на спокойный интерфейс, персонализацию и привычное общение без перегруженного UI.

Проект построен как полноценное multi-user приложение с авторизацией, профилями, личными диалогами, сообщениями в реальном времени, вложениями и пользовательскими настройками.

## Возможности

- регистрация и вход по email
- подтверждение аккаунта
- профили пользователей
- загрузка аватаров и история аватаров
- поиск пользователей
- личные диалоги
- сообщения в реальном времени
- изображения и файлы в сообщениях
- поиск по сообщениям
- emoji
- статусы онлайн / офлайн
- закрепление диалогов
- архивирование чатов
- отключение уведомлений для отдельных диалогов
- блокировка пользователей
- список заблокированных пользователей
- индивидуальные темы диалогов
- светлая и тёмная тема интерфейса
- личный раздел «Черновик»
- адаптивная версия для desktop и mobile
- установка на устройство как PWA

## Интерфейс

Apchi использует собственную визуальную систему с мягкой цветовой палитрой и минимальным количеством отвлекающих элементов.

Основные разделы:

- **Чаты** — текущие диалоги
- **Черновик** — личные заметки
- **Друзья** — пользователи, с которыми уже была переписка
- **Архив** — архивированные диалоги

Для каждого диалога можно отдельно выбрать цветовую тему:

- Как в системе
- Крем
- Сумерки
- Шалфей
- Вишня
- Луна

## Безопасность

Доступ к данным пользователей ограничивается на уровне Supabase Row Level Security.

Пользователь может работать только со своими настройками, черновиками и диалогами, участником которых он является.

Доступ к сообщениям, профилям и загруженным файлам также контролируется backend-политиками.

## PWA

Apchi можно использовать как обычное веб-приложение или установить на главный экран устройства.

После установки приложение запускается в отдельном окне без стандартного интерфейса браузера.

Поддерживается установка на:

- Android
- iPhone / iPad
- desktop-браузеры с поддержкой PWA

## Локальный запуск

Установить зависимости:

```bash
npm install
```

Запустить development-сервер:

```bash
npm run dev
```

Для подключения Supabase необходимо создать `.env.local`:

```env
VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=
```

Пример переменных окружения находится в `.env.example`.

## Production build

```bash
npm run build
```

Готовая production-сборка создаётся в директории `dist`.

## Структура проекта

```text
src/
├── components/
├── pages/
├── services/
├── hooks/
├── lib/
└── ...

supabase/
├── migrations/
├── config.toml
└── schema.sql
```

`schema.sql` содержит актуальную схему базы данных.

Директория `migrations` содержит историю изменений схемы проекта.
