# Apchi — Stage 1.1

Исправления после первого ручного теста.

## Что исправлено

- заменён CSS-логотип на стабильный SVG-логотип Apchi;
- слово `apchi` получило мягкий rounded-wordmark;
- логотип кликабельный и возвращает в `/chats`;
- плавное переключение Вход / Регистрация;
- убрана подсказка `wakukiku` из поля username;
- после регистрации с подтверждением email открывается отдельный экран «Подтвердите почту»;
- светлая тема получила заметную, но спокойную внешнюю рамку приложения;
- исправлено положение пустого состояния «Выберите диалог»;
- `window.prompt()` в Черновике заменён на нормальное модальное окно;
- исправлена загрузка профиля после появления второго аккаунта;
- без аватарки показывается первая буква username;
- добавлена постоянная галерея аватарок через Supabase Storage;
- аватарки можно выбирать, листать и удалять;
- «Люди» переименованы в «Друзья»;
- «Возможные друзья» вынесены в отдельный экран и открываются кнопкой снизу;
- пользовательские интересы больше не разрастаются в глобальную панель фильтров;
- мобильные горизонтальные скроллы скрывают scrollbar;
- удалены аудио/видеозвонки;
- нерабочие кнопки вложений временно убраны до реальной реализации через Supabase Storage;
- поиск по сообщениям теперь работает;
- эмодзи-панель работает;
- индивидуальные темы диалога теперь заметно меняют реальные цвета сообщений;
- добавлено сохранение позиции прокрутки в диалоге;
- новый realtime message не бросает пользователя вниз, если он читает историю;
- после отправки сообщения input снова получает focus;
- добавлено отображение ошибки отправки вместо молчаливого сбоя.

## Критические backend-исправления

В исходной версии политика RLS `conversation_members` читала саму себя,
что могло вызывать recursive RLS / проблемы с чтением и отправкой сообщений.

Также `getMyProfile()` использовал `.single()` без фильтра по текущему user id,
поэтому после регистрации второго пользователя профиль мог перестать загружаться.

Оба дефекта исправлены.

## Что сделать после замены файлов

В Supabase SQL Editor выполните ОДИН раз:

```text
supabase/migrations/002_stage_1_1.sql
```

Не запускайте повторно старый `schema.sql` в существующей базе.

После этого:

```bash
npm install
npm run dev
```

`.env.local` сохраняйте свой — в архив он намеренно не включён.

## Инкогнито

Несколько вкладок в одном incognito-сеансе используют одну browser session.
Это нормальное поведение. После закрытия всех incognito-окон сессия исчезает.
Другой browser profile / устройство / новый incognito-сеанс потребует авторизацию.
